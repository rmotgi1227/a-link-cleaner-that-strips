# A Link Cleaner That Strips

A browser-based link cleaner that removes tracking IDs — including `utm_*`, `si=`, `fbclid`, `gclid`, and friends — from any URL you paste.

Asked for by Iampepeu.

Open `index.html` in any modern web browser. No install, no build, and no server required.
